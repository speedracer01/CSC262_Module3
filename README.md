# CSC262_Module3
Module 3 Discussion 

	Module 3 discussion will be about arrays and ArrayLists. Arrays are a fixed size. They store same-type elements. ArrayLists are dynamic and can grow and shrink as needed. Unlike arrays, ArrayLists store objects. These objects have built-in methods for manipulation. In relation to dimensionality, an array can be both single or multi-dimensional while an Arraylist can only be single-dimensional. You may be wondering what dimensionality is. Dimensionality refers to the amount of indexes or levels required to access the data. For instance, an array can have two rows also known as a 2D array. 
  
	When it comes to scouring the elements, the tools also vary. While the Foreach loop is available to both, Array uses the for loop and the ArrayList uses the iterator and listIterator. The iterator only can move forward while the ListIterator can move both forward and backwards among the elements. Regarding the size and length, the array is a fixed size dependent on the number of elements entered into the array. To use the ArrayList in your code “ArrayList<integer> list = new ArrayList<>();”. Theoretically, the size of the ArrayList is limited only by the amount of RAM. 
  
	Arrays operate at a faster pace due to fixed size. ArrayList are slower. This is due to its dynamic behavior. It is constantly resizing. The way that arrays and ArrayList store primitive datatypes are different as well. Example of some of the primitive datatypes are int, double, char, and Boolean. Arrays store these datatypes directly. The ArrayList do not directly add datatypes. Instead the datatypes are added indirectly with assistance from converters known as autoboxing and unboxing. Autoboxing converts the primitive datatype in an object and unboxing converts the object into a primitive. The way to add elements also differ. To add elements, arrays use “(arr[0] = value)” while arraylist uses “add()”.
